# How to participate

This repository is a public description of [YearlyRank AI Tool](https://aitool.yearlyrank.com). It is not the production source tree.

You can suggest a new AI tool family, or a correction to an existing listing, in any of these ways:

1. **Open a GitHub issue** with the [tool submission template](.github/ISSUE_TEMPLATE/tool-submission.md).
2. **Open a pull request** that adds a row to [data/tool-suggestions.md](data/tool-suggestions.md).
3. **Email** the same details to [contact@yearlyrank.com](mailto:contact@yearlyrank.com).

Please include:

- Tool name
- Official website
- Type (`app`, `agent`, `model`, or `api`)
- Suggested category (see the [category list](https://aitool.yearlyrank.com/category/))
- Evidence links for the launch date and that the product is still operating in 2026 (official announcement, documentation, or another official source)

## Inclusion criteria

Listings on the site are AI tool families that are **still operating in 2026**, with facts checked against **verified official sources**. Every suggestion is reviewed by a person. Listing is not guaranteed, and neither is a place in the ranking or a score.

Please do not send unofficial mirrors, unofficial round-up blogs, or unsourced claims as the only evidence.

## Scores are not changed by submissions

Official scores and positions come **only from public signals**, as described on the [methodology page](https://aitool.yearlyrank.com/rank/methodology/). A submission, a community star, or a comment does not change an official score. Families with too few countable signals are marked “insufficient data”; some families are marked “method under review”. Those families are not given a score of 0 and are not placed last as if they had been ranked.

## Corrections

If a name, official website, type, category, or operating status on the site looks wrong, use the same issue, pull request, or email path, and include the official source you are relying on.
